          DWH TRANSFERMARKT - STACK TECNOLÓGICO Y HERRAMIENTAS UTILIZADAS
================================================================================

1. MOTOR DE BASE DE DATOS Y GESTIÓN DE ALMACENAMIENTO
--------------------------------------------------------------------------------
- PostgreSQL (v14+ / v16 en Docker / v18 local):
  * Motor relacional para el Data Warehouse.
  * Implementación de Arquitectura Medallón mediante esquemas aislados:
    - bronze: Ingesta cruda de CSVs, tipos de datos TEXT, carga por bloques masivos con COPY.
    - silver: Datos tipados, limpios, normalizados, reglas de calidad EDA E01-E10, PK/FK, CHECK.
    - gold: Modelo de Constelación de Hechos (Kimball Bus Architecture) con dimensiones conformadas:
      * Dimensiones: dim_fecha, dim_competicion, dim_club, dim_jugador, dim_arbitro, dim_tipo_evento, dim_partido.
      * Tablas de Hechos: hecho_rendimiento_jugador, hecho_eventos_partido, hecho_valoraciones_mercado.
      * Agregaciones Materializadas: agg_jugador_temporada_liga, agg_club_temporada, agg_eventos_15min, agg_disciplina_arbitro, agg_local_visitante.
    - meta: Auditoría transversal de pipeline en meta.etl_audit y registro de calidad/descartes en meta.etl_rejected.
  * Particionamiento declarativo por rango (Range Partitioning) anual en gold.hecho_eventos_partido (1990–2035).
  * Vistas materializadas con índices únicos para refresco concurrente sin bloqueo (REFRESH MATERIALIZED VIEW CONCURRENTLY).
  * Optimización física de almacenamiento con índices B-Tree y Hash.
  * Funciones y lógica procedimental en PL/pgSQL y consultas set-based.

2. LENGUAJE Y ENTORNO DE DESARROLLO
--------------------------------------------------------------------------------
- Python (v3.10+ / v3.12 / v3.13 / v3.14):
  * Lenguaje principal para la orquestación del pipeline ETL y scripts de automatización.
  * Entorno virtual aislado (.venv) gestionado con venv / uv.
- PowerShell (Windows) / Bash (Linux):
  * Entorno de consola y scripting para automatización de comandos CLI del sistema operativo.

3. LIBRERÍAS Y DEPENDENCIAS DE PYTHON (requirements.txt)
--------------------------------------------------------------------------------
- pandas:
  * Lectura eficiente por chunks (RNF01) y normalización tabular durante la ingesta cruda.
- psycopg2-binary:
  * Driver PostgreSQL nativo en C de alto rendimiento para ejecución masiva y transacciones.
- python-dotenv:
  * Carga segura de variables de entorno desde .env sin versionar credenciales sensibles.
- pytest:
  * Framework de pruebas unitarias y de integración para verificación automatizada de esquemas,
    claves foráneas, unicidad, integridad referencial, linaje, idempotencia y reversibilidad.

4. CLIENTES DE BASE DE DATOS Y CONSULTA
--------------------------------------------------------------------------------
- DBeaver Community Edition:
  * Cliente gráfico multipropósito para administración de PostgreSQL, visualización de datos,
    navegación de esquemas y generación de diagramas Entidad-Relación (ER).
- psql:
  * Interfaz de línea de comandos oficial de PostgreSQL para administración y scripts.
